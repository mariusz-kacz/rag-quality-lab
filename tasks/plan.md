# Answer-focused evaluation

1. Define success with editable grading notes on each golden question.
2. Judge each answer with one native Ragas pass/fail metric and explanation.
3. Retain faithfulness and clearly named source coverage as supporting metrics.
4. Keep routing, citation and refusal detection as diagnostics.
5. Run questions, save answers, score one Ragas experiment, and print a summary.
6. Verify offline behavior; document human review needed for judge validation.

See [usage](../README.md#evaluation) and [contract](../SPEC-ragas-evaluation.md).
